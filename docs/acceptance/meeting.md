# 会议模式验收场景

场景 ID 前缀 `MEET-`，全局唯一。规则来源见 [会议模式需求](../requirements/meeting.md)。

| ID | Given / When / Then |
| --- | --- |
| MEET-001 | Given 个人模式 / When 在侧栏切到「会议」/ Then 显示会议工作区，不开始录音；切回「个人」后 Fn 听写照常 |
| MEET-002 | Given 会议工作区 / When 点「开始会议」并说话 / Then 出现录音告知提示；每句话说完 1～3 秒内出现在列表中，带说话人与时间；胶囊显示「会议中 hh:mm:ss」 |
| MEET-003 | Given 会议进行中 / When 按 Fn / Then 不开始听写，胶囊提示“会议进行中” |
| MEET-004 | Given 会议进行中 / When 暂停后再继续 / Then 暂停期间不录音、不转写，继续后接着记录 |
| MEET-005 | Given 两人交替说话的会议（包括一人说完另一人立刻接话、中间不停顿）/ When 会议进行 / Then 两人的话自动分别标为不同说话人；点说话人栏或发言前的名字改名后，该说话人所有段落同步显示新名字 |
| MEET-006 | Given 某段被标错说话人 / When 把它改归另一个人，或合并两个说话人 / Then 显示与之后生成的纪要都按纠正后的结果 |
| MEET-007 | Given 改名时保持「记住这个声音」默认勾选 / When 下一场会议同一人说话 / Then 自动标出其名字；在设置里删除该声纹后不再自动认出 |
| MEET-008 | Given 已配置 LLM / When 结束会议并选择「生成纪要」/ Then 自动生成每人发言总结与会议纪要（主题、时间、参会人、议题要点、决议、待办、未决问题）；临时录音被删除 |
| MEET-009 | Given 未配置 LLM Key / When 结束会议并选择「生成纪要」/ Then 转写稿完整保存，提示配置 LLM 后可生成纪要 |
| MEET-010 | Given 会议进行中 / When 应用异常退出后重新打开 / Then 已转写的内容都在，提示继续整理该会议 |
| MEET-011 | Given 一场已结束的会议 / When 编辑纪要并导出 / Then 得到 Markdown 文件，内容与编辑后一致 |
| MEET-012 | Given 会议进行 1 小时 / When 同时使用其他应用 / Then 没有明显卡顿；最后 5 分钟（第 4 小时）提醒，到时自动结束并整理 |
| MEET-014 | Given 会议进行中 / When 点「结束会议」选择「只保存记录」（或在胶囊、托盘上选择）/ Then 不调用 LLM，转写与说话人完整保存，临时录音删除；之后在纪要页点「生成纪要」可补生成 |
| MEET-015 | Given 一场会议的参会人数设错了 / When 在说话人栏把人数改为「2 人」（会议中或会后）/ Then 立即重新区分为 2 个说话人，各句归属正确 |
| MEET-019 | Given 两人开会已说了几轮 / When 一人说完另一人立刻接话（几乎不停顿），持续一段时间 / Then 两人的话分别标为各自的名字，不会整段记成其中一个人 |
| MEET-018 | Given 两人开会，其中一人离 Mac 两三米说话 / When 会议进行 / Then 他说的每一句都出现在转写里（不被当成静音漏掉），文字大体正确；会议结束后临时录音照常删除 |
| MEET-017 | Given 上一场会议给两个人改名并记住声音 / When 新开一场（同样两人、参会 2 人）各说几句 / Then 会议中约 20 秒内两人自动标出各自的名字，不会两人标成同一个名字；没保存过声纹的人仍显示「说话人 N」 |
| MEET-016 | Given 开始会议时选「参会 2 人」/ When 两人对话，其中一人只说了几句短话 / Then 会议中和整理后都始终是 2 个说话人，说得少的一方不被并入另一人；下次开会默认仍是 2 人 |
| MEET-013 | Given 声纹模型未下载 / When 在设置 → 声纹 点「下载」后中途取消，再点「下载」 / Then 显示进度，取消后再下载从断点继续，完成后显示「已下载」；会议进行中不能删除模型 |
| MEET-020 | Given macOS 14.2+、正在用腾讯会议（或飞书、Zoom、网页会议）开线上会议 / When 开始会议时选「只用会议软件的声音」并选中该应用 / Then 对方说的每句话都出现在转写里，按所选人数区分说话人；我自己说的话不被录下 |
| MEET-021 | Given 现场 2 人围着 Mac、线上 2 人在会议软件里 / When 选「麦克风 + 会议软件」、现场 2 人、线上 2 人开会 / Then 说话人栏分「现场」「线上」两组各 2 人，各句归到正确的一组；改人数只重新区分那一组 |
| MEET-022 | Given 麦克风 + 会议软件、用扬声器外放 / When 线上的人说话 / Then 这句话只出现在线上，不会在现场再出现一遍；现场的人同时插话时，现场的话仍然保留；开会时与检测到回声时提示建议戴耳机 |
| MEET-023 | Given 从没授权过「录制系统音频」/ When 在开始会议卡片里选「麦克风 + 会议软件」或「只用会议软件的声音」/ Then 系统弹出授权框；没回应前点「开始会议」不会开始，提示先允许；允许后 MyTypeless 重新打开，再开会正常截取 |
| MEET-024 | Given 线上会议进行中 / When 插拔耳机（或连上蓝牙耳机）/ Then 转写不中断，两路时间仍对齐；会议结束后两份临时录音都被删除 |
| MEET-025 | Given macOS 低于 14.2 / When 打开开始会议卡片 / Then 「麦克风 + 会议软件」「只用会议软件的声音」不可选，并说明需要 macOS 14.2 |
