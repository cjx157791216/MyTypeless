# 会议模式验收场景

场景 ID 前缀 `MEET-`，全局唯一。规则来源见 [会议模式需求](../requirements/meeting.md)。

| ID | Given / When / Then |
| --- | --- |
| MEET-001 | Given 个人模式 / When 在侧栏切到「会议」/ Then 显示会议工作区，不开始录音；切回「个人」后 Fn 听写照常 |
| MEET-002 | Given 会议工作区 / When 点「开始会议」并说话 / Then 每句话说完 1～3 秒内出现在列表中，带说话人与时间；胶囊默认隐藏，设置 → 会议 勾选后显示「会议中 hh:mm:ss」（D-049，2026-11-11 起不再弹录音告知提示，D-048） |
| MEET-003 | Given 会议进行中 / When 按 Fn / Then 不开始听写，胶囊提示“会议进行中” |
| MEET-004 | Given 会议进行中 / When 暂停后再继续 / Then 暂停期间不录音、不转写，继续后接着记录 |
| MEET-005 | Given 两人交替说话的会议（包括一人说完另一人立刻接话、中间不停顿）/ When 会议进行 / Then 两人的话自动分别标为不同说话人；点说话人栏或发言前的名字改名后，该说话人所有段落同步显示新名字 |
| MEET-006 | Given 某段被标错说话人 / When 把它改归另一个人，或合并两个说话人 / Then 显示与之后生成的纪要都按纠正后的结果 |
| MEET-007 | Given 改名时保持「记住这个声音」默认勾选 / When 下一场会议同一人说话 / Then 自动标出其名字；在设置里删除该声纹后不再自动认出 |
| MEET-008 | Given 已配置 LLM / When 结束会议并选择「生成纪要」/ Then 自动生成每人发言总结与会议纪要（主题、时间、参会人、议题要点、决议、待办、未决问题）；临时录音被删除 |
| MEET-009 | Given 未配置 LLM Key / When 结束会议并选择「生成纪要」/ Then 转写稿完整保存，提示配置 LLM 后可生成纪要 |
| MEET-010 | Given 会议进行中 / When 应用异常退出后重新打开 / Then 已转写的内容都在，提示继续整理该会议 |
| MEET-011 | Given 一场已生成纪要的会议 / When 在纪要页编辑后点「导出 Markdown」/ Then 得到「…-纪要.md」，内容与编辑后的纪要一致（不含完整记录） |
| MEET-012 | Given 会议进行 1 小时 / When 同时使用其他应用 / Then 没有明显卡顿；最后 5 分钟（第 4 小时）提醒，到时自动结束并整理 |
| MEET-014 | Given 会议进行中 / When 点「结束会议」选择「只保存记录」（或在胶囊、托盘上选择）/ Then 不调用 LLM，转写与说话人完整保存，临时录音删除；之后在纪要页点「生成纪要」可补生成 |
| MEET-015 | Given 一场会议的参会人数设错了 / When 在说话人栏把人数改为「2 人」（会议中或会后）/ Then 立即重新区分为 2 个说话人，各句归属正确 |
| MEET-019 | Given 两人开会已说了几轮 / When 一人说完另一人立刻接话（几乎不停顿），持续一段时间 / Then 两人的话分别标为各自的名字，不会整段记成其中一个人 |
| MEET-018 | Given 两人开会，其中一人离 Mac 两三米说话 / When 会议进行 / Then 他说的每一句都出现在转写里（不被当成静音漏掉），文字大体正确；会议结束后临时录音照常删除 |
| MEET-017 | Given 上一场会议给两个人改名并记住声音 / When 新开一场（同样两人、参会 2 人）各说几句 / Then 会议中约 20 秒内两人自动标出各自的名字，不会两人标成同一个名字；没保存过声纹的人仍显示「说话人 N」 |
| MEET-016 | Given 开始会议时选「参会 2 人」/ When 两人对话，其中一人只说了几句短话 / Then 会议中和整理后都始终是 2 个说话人，说得少的一方不被并入另一人；下次开会默认仍是 2 人 |
| MEET-013 | Given 声纹模型未下载 / When 在设置 → 声纹 点「下载」后中途取消，再点「下载」 / Then 显示进度，取消后再下载从断点继续，完成后显示「已下载」；会议进行中不能删除模型 |
| MEET-020 | Given macOS 14.2+、正在用腾讯会议（或飞书、Zoom、网页会议）开线上会议 / When 开始会议时选「只用会议软件的声音」并选中该应用 / Then 对方说的每句话都出现在转写里，按所选人数区分说话人；我自己说的话不被录下 |
| MEET-021 | Given 现场 2 人围着 Mac、线上 2 人在会议软件里 / When 选「麦克风 + 会议软件」、现场 2 人、线上 2 人开会 / Then 说话人栏分「现场」「线上」两组各 2 人，各句归到正确的一组；改人数只重新区分那一组 |
| MEET-022 | Given 麦克风 + 会议软件、用扬声器外放 / When 线上的人说话 / Then 这句话只出现在线上，不会在现场再出现一遍；现场的人同时插话时，现场的话仍然保留；开会时与检测到回声时提示建议戴耳机 |
| MEET-023 | Given 从没授权过「录制系统音频」/ When 在开始会议卡片里选「麦克风 + 会议软件」或「只用会议软件的声音」/ Then 系统弹出授权框；没回应前点「开始会议」不会开始，提示先允许；允许后 MyTypeless 重新打开，再开会正常截取 |
| MEET-024 | Given 线上会议进行中 / When 插拔耳机（或连上蓝牙耳机）/ Then 转写不中断，两路时间仍对齐；会议结束后两份临时录音都被删除 |
| MEET-025 | Given macOS 低于 14.2（或 Windows 低于 build 20348） / When 打开开始会议卡片 / Then 「麦克风 + 会议软件」「只用会议软件的声音」不可选，并说明需要 macOS 14.2（Windows 11） |
| MEET-026 | Given 已配置 LLM（包括强制深度思考的模型）/ When 一场 2 小时的会议生成纪要，中途某一段失败后再点「生成纪要」/ Then 进度显示“正在整理各段（k/n）”，重试只补失败的段，最终生成完整纪要，不因上下文或超时失败 |
| MEET-027 | Given 开着腾讯会议、微信、Chrome，以及预览、Excel 等其他应用 / When 开始会议、声音来源选会议软件 / Then 应用列表只有腾讯会议、微信、Google Chrome（网页会议）、全部系统声音、其他应用…，默认选中腾讯会议；选「其他应用…」后才出现预览、Excel；关掉腾讯会议再回到主窗口，列表里不再有它（D-039） |
| MEET-028 | Given 参会人数选「自动」，现场 2 人各说 10 句以上 / When 开会并结束整理 / Then 会中约 1 分钟内分出 2 人、说话人栏显示「自动（2 人）」，整理后仍为 2 人；改成 3 人立即按 3 人重新区分，再改回自动又按声音判断（D-042） |
| MEET-029 | Given 参会人数选「自动」/ When 只有 1 个人说了 10 分钟（含咳嗽、笑声、离麦远的话）/ Then 始终只有 1 个说话人 |
| MEET-030 | Given 已保存 A 的声纹，B 从没保存过 / When A、B 开会（自动或选 2 人）/ Then A 说过三句后约 20 秒内标出 A 的名字，B 不被标成 A 或声纹库里的其他人；整理结束后 A 的名字仍在、A 的声纹被更新 |
| MEET-031 | Given 现场 3 人围坐一张桌子开会（选 3 人或自动），A、B 说得多、C 说得较少 / When 会议进行中给 A 改名，之后继续开 20 分钟以上 / Then C 的话分到单独的说话人（已保存 C 的声纹时标出 C 的名字），不会持续并进 A；A 的名字留在 A 自己的话上 |
| MEET-032 | Given 设置 → 会议 勾选「保存会议录音」并选了一个文件夹 / When 开一场「麦克风 + 会议软件」的会议并结束 / Then 文件夹里出现「日期 时间 主题.wav」，能直接播放、现场与对方的声音都在；会议详情「显示录音」在访达 / 资源管理器里选中它；删除这场会议后录音文件还在；取消勾选后的下一场会议不再保存（D-044） |
| MEET-033 | Given 用微信（或腾讯会议）语音通话、现场只有自己 / When 开始会议时选「只用会议软件的声音」并选该软件，通话中自己和对方都说话 / Then 通话接通（软件开始用麦克风）后浮动条提示“已同时录下你的麦克风”，说话人栏分「现场」「线上」两组，自己说的话出现在现场、对方的在线上；挂断后不再录麦克风；开启保存会议录音时保存的 WAV 里有双方的声音；只开着会议软件、没在通话时不录麦克风 |
| MEET-034 | Given 设置里保存过一场会议的录音（WAV）/ When 在会议页点「导入录音」→「导入，只保存记录」并选这个文件 / Then 立即出现一场以录音文件名里的日期、主题命名的会议，详情显示“正在转写录音（n%）”，完成后转写与说话人与原会议大体一致；「显示录音」定位到原文件；删除这场会议后原文件仍在 |
| MEET-035 | Given 一个 MP3（44.1kHz 立体声、8kHz 单声道都可）/ When 导入并生成纪要 / Then 立即建会议、按文件名作主题，转写与说话人区分照常进行；Given 一个损坏的或不是录音的文件 / When 导入 / Then 提示「不是支持的录音格式」之类的原因，不建会议；会议进行中时「导入录音」不可点 |
| MEET-036 | Given 润色 LLM 配置为本机 ollama 模型（如 12B，不调大上下文），转写稿超过 1.2 万字 / When 生成纪要 / Then 各段请求串行进行（浮动条进度逐段推进），每次发给模型的内容不超过约 3000 字（默认 4k 上下文也放得下），最终能生成完成、内容覆盖全场，不再报「服务器还没有开始输出」；换回云端模型后仍按最多 3 段同时整理、每段约 1.2 万字（D-047） |
| MEET-037 | Given 同一场已结束的会议 / When 切到转写页点「导出 Markdown」（转写区右上）/ Then 得到「…-转写.md」（会议信息头部 + 完整记录），纪要没生成也能导出；纪要页的导出按钮在「编辑」左边、没有纪要时置灰（生成后可点）；说话人页没有导出按钮；文件名分别带「纪要」「转写」后缀 |
| MEET-038 | Given 一场已生成纪要、内容里有流程 / 架构等可画内容的会议（D-048）/ When 打开详情 / Then 「纪要」右边出现「图表」标签，里面有最多 3 张图（标题 + 图，可横向滚动），渲染失败的按原文显示代码；Given 内容里没有可画内容的会议 / Then 不出「图表」标签；「重新生成」纪要后图表随之更新；整理中浮动条胶囊不显示步骤文字（回到空闲样式），进度只在会议详情页 |
| MEET-039 | Given 会议列表有多场会议 / When 新建文件夹「工作例会」、把两场会议移动进去、再重命名文件夹 / Then 侧栏「全部会议 / 未分类 / 工作例会」的计数随之变化，选中文件夹只显示其中会议；移动到「未分类」后会议不再属于任何文件夹；新建的会议出现在「未分类」 |
| MEET-040 | Given 文件夹里有会议 / When 删除该文件夹 / Then 文件夹消失，其中会议（含回收站里的）全部出现在「未分类」，数据不丢；删除时有确认说明「会议会移到未分类，不会删除会议」 |
| MEET-041 | Given 一场已结束的会议 / When 点删除（或详情页删除按钮）/ Then 会议进入回收站（侧栏计数 +1），主列表与「继续整理」横幅不再显示它；回收站里选「恢复」→ 会议回到原文件夹；选「彻底删除」并确认 → 文字、说话人数据与临时录音删除（userData/meetings/ 里对应文件消失），用户另存的录音文件仍在；回收站为空时显示空态 |
| MEET-042 | Given 会议较多 / When 在列表上方输入标题关键词 / Then 只显示匹配的会议（无结果时空态提示）；点排序按钮在「最新优先 / 最早优先」之间切换列表顺序；会议进行中或整理中时行菜单里的「移到回收站」不可用（提示原因） |
