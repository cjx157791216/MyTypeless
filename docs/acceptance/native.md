# 原生层验收场景

场景 ID 前缀 `NATI-`，全局唯一。规则来源见 [原生层需求](../requirements/native.md)。

| ID | Given / When / Then |
| --- | --- |
| NATI-001 | Given 已授权辅助功能 / When 在任意输入框按住 `Fn` 再按 `Shift` / Then 进入翻译模式录音（免手持），目标应用不收到任何字符；再按一下 `Fn` 结束并写入译文 |
| NATI-002 | Given 已授权 / When 按住 `Fn` 说话中途停顿 3 秒再继续 / Then 录音不被中断，松开后才结束并写入 |
| NATI-003 | Given 未授权辅助功能 / When 启动应用并按 `⌥+空格` / Then 按一下开始录音、再按一下结束；在系统设置中授权后数秒内切换为按住说话，无需重启 |
| NATI-004 | Given 剪贴板里有一张图片 / When 以粘贴方式写入文字后 / Then 剪贴板恢复为原图片 |
| NATI-005 | Given 已授权 / When 轻按一下 `Fn`（不超过 0.3 秒）后说话 / Then 浮动条进入免手持（显示取消与完成），说完再按一下 `Fn` 结束并写入 |
| NATI-006 | Given 在文本框选中一段文字 / When 按住 `Fn` 说“改成英文”后松开 / Then 选区被替换为英文改写结果，剪贴板内容不变 |
| NATI-007 | Given 按住 `Fn` / When 再按 `空格` / Then 不录入听写，改为语音提问（免手持），目标应用不收到空格 |
| NATI-008 | Given 按住 `Fn` / When 按方向键 / Then 放弃本次听写，方向键照常生效 |
| NATI-009 | Given 系统「按下 🌐 键时」为「显示表情与符号」、主键为 Fn / When 按住 Fn 说一句话后松开 / Then 正常录音并写入；录音开始时胶囊提示把「按下 🌐 键时」改为「无操作」，写完后自动打开键盘设置（同一次启动内不再自动打开）；改为「无操作」后不再提示（D-043） |
