# 界面与存储验收场景

场景 ID 前缀 `UI-`，全局唯一。规则来源见 [界面与存储需求](../requirements/ui.md)。

| ID | Given / When / Then |
| --- | --- |
| UI-001 | Given 首次启动且未配置 ASR Key / When 应用启动 / Then 打开主窗口；配置完成且已授权后再次启动不弹主窗口 |
| UI-002 | Given 应用运行中 / When 查看菜单栏 / Then 可见麦克风托盘图标，菜单可打开主窗口与历史 |
| UI-003 | Given 主窗口首页 / When 打开 / Then 状态卡片显示辅助功能、麦克风、快捷键引擎的当前状态 |
| UI-004 | Given 历史中有记录 / When 点“清空”并确认 / Then 全部记录被删除 |
| UI-005 | Given 首次启动、使用内置引擎 / When 打开主窗口 / Then 首页显示“首次使用：下载语音识别模型”与大小；点击下载后显示百分比与速度，可取消，再次下载从已下载处继续，完成后提示已就绪 |
| UI-006 | Given 主键为 `Fn` 且系统「按下 🌐 键时」不是「无操作」 / When 打开主窗口 / Then 权限面板显示提示与“打开键盘设置”按钮；改为「无操作」后刷新状态提示消失 |
| UI-007 | Given 浮动条显示中 / When 点击胶囊旁边的透明区域 / Then 点击落到下面的应用上，不被浮动条拦截 |
| UI-008 | Given 安装后启动 MyTypeless / When 查看 Dock 并按 ⌘Tab / Then Dock 有运行中的图标，⌘Tab 能切换到它 |
| UI-009 | Given 主窗口 / When 点侧栏「会议」切换 / Then 导航只剩「会议」与「设置」，显示会议工作区；切回「个人」显示首页、历史、词典；重新打开主窗口时停在上次的模式 |
| UI-010 | Given 已有若干听写记录 / When 打开首页 / Then 概览数字与历史一致，最近记录显示最新几条，快捷键速查与设置中的绑定一致 |
| UI-011 | Given 会议进行中 / When 查看浮动条与主窗口侧栏 / Then 胶囊显示「会议中」计时与暂停/结束按钮；侧栏显示会议状态，点击进入该会议 |
| UI-012 | Given 用 `npm run dist` 打出的安装包 / When 安装后打开主窗口、托盘菜单与 设置 → 关于 / Then 显示的版本与构建号与安装包文件名 `MyTypeless-<版本>-<构建号>-arm64.dmg` 一致 |
| UI-013 | Given 设置 → 润色 LLM 填了地址、模型和 Key（未保存）/ When 点「测试连接」/ Then 配置正确时几秒内显示“✓ 连通正常（x.x 秒）”；把 Key、地址或模型名改错后再点，分别显示 Key 无效、地址或模型不存在 / 不是 OpenAI 兼容格式、请求被拒绝（模型名）等原因，并附服务端原话 |
| UI-014 | Given 两个个性化开关都关闭 / When 打开「参考光标前的文字」/ Then 弹确认框写明会发送到所配置的 LLM 地址，点取消则保持关闭；修改记录为空时显示说明，逐条删除和清空立即生效（D-040、D-041） |
