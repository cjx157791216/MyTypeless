# 2026-10-17 发布 0.3.0

## 范围

GAP-020（D-028、D-032）：发布 0.3.0，包含线上会议（#3，D-033）、去掉 FireRedASR2 的 `<sil>`（#4）、没有实际内容时不调用 LLM（#5，D-034）。顺带修复发布脚本在本次发布中暴露的两个问题。

## 改动

- 版本号 0.2.1 → 0.3.0（#6），在干净的 main（33e26dd）上 `npm run dist`，构建 20261017.2029，本机证书签名。
- 发布到代码仓库 v0.3.0，并在旧发布仓库同步版本说明。
- `scripts/publish.cjs`：终端设了 `HTTPS_PROXY` 时带 `NODE_USE_ENV_PROXY=1` 重新运行自己（Node 的 fetch 默认不走代理，110MB 的 zip 直连上传到一半断开）；发布后核对版本改为 `waitForVersion` 重读（latest 地址有缓存，刚发布时读到旧版本导致脚本退出、旧发布仓库没有同步，本次用 `gh release create` 手动补上）。

## 验证

- 发布前：typecheck、test、build、docs:check 通过；打包版隔离实例启动正常；`codesign --verify --deep --strict` 通过。
- 发布后：两个仓库的 `releases/latest/download/latest-mac.yml` 都读到 0.3.0；GitHub 上三个文件的 SHA-256 与本地一致。
- 脚本修复：`test/update.test.ts` 新增 `waitForVersion` 用例，全部通过；设代理时计划模式能读到已发布版本。
