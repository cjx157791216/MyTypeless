# 2026-10-19 会议详情头部固定、纪要里的说话人名字加粗

## 范围

会议详情页布局（D-017）与会议纪要（meeting.md 第 15 条）。只改显示与纪要正文的标记，不改提示词、不改数据结构。

## 改动

- 会议详情：标题、录音/整理状态条、说话人栏、标签页固定在顶部，只有 `#meeting-detail-scroll`（纪要/转写/说话人内容）滚动，滚动条从标签栏下方开始；`#page-meeting.detail-mode` 让页面撑满内容区。会中转写自动滚到底改用新的滚动区；切换会议时滚回顶部。
- 纪要：生成后在本地给说话人名字加粗（`src/shared/speaker-mentions.ts` 的 `markSpeakerNames`），参会人一行也加粗；复制、导出带着 `**名字**`。界面把正好是说话人名字的粗体显示成该说话人的颜色。单字名字只在句首、标点或介词后，且后接标点或常见动词时才算，避免“完成”“成本”等误标。
- 用户在三种标记写法（粗体 / `==高亮==` / `<mark>`）与标记方式（本地规则 / 模型）中选了粗体 + 本地规则。
