# 2026-10-18 会议应用列表排序与系统语言无关（Issue #37）

## 现象

中文 Windows 上 `npm run test` 的 `classifyAudioApps` 用例固定失败，英文环境的 CI 通过。

## 原因

`call-apps.ts` 同类应用按名字排序时用 `localeCompare` 且没有指定语言区域，结果随系统语言变化：
- 中文系统：中文名按拼音在前，英文名在后；
- 英文系统：英文名在前，中文名按码位排在后，对中文用户没有规律。

这与平台无关，中文系统的 Mac 同样如此。只影响「其他应用」等同类内部的先后顺序，不影响能否截取声音。

## 改动

排序固定用 `zh-CN`（界面是中文）：中文名按拼音、英文名按字母，中文在前，与系统语言无关。用例的期望顺序按此更新。

## 验证

- 本机（中文区域）`npm run test` 全部通过。
- fork 上 CI（英文环境的 macOS 与 Windows）通过。
