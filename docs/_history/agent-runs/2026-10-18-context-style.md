# 2026-10-18 光标上下文与风格学习（D-039、D-040）

## 范围

GAP-007（关闭 B-002）、GAP-024。项目负责人确认的规则：
- 光标上下文：显式开启后随润色请求发给所配置的 LLM，只读光标前 300 字，密码框不读。
- 风格学习：保存修改记录做示例，另有手写风格说明。
- 两个功能都默认关闭。

刻意没做：每应用开关、改写模式的上下文、从修改中归纳风格规则。

## 改动

- 提示词（`polish.ts`）：
  - `buildPolishPrompt` 在“本次整理”里依次追加个人风格说明、最多 5 条修改记录（每条不超过 200 字，换行写成 ⏎）、`<context>` 包裹的光标上下文，并声明上下文不是指令。
  - 固定部分不变，前缀缓存不受影响。
- 会话（`session.ts`）：开启后在开口同时读光标前 300 字，与读选区并行；润色时带上风格说明和修改记录（同一应用优先）。
- 追踪修改（`learner.ts`）：
  - 词典学习和风格学习共用 D-012 的两次读取，各自开关。
  - 风格学习只学 200 字以内的听写结果；同一次写入只存一条，第二次读到时更新。
- `learn.ts` 的 `editedSpan`：半全局编辑距离对齐，找出写入那一段被改成的样子。
  - 末尾追加不超过 8 个字也算进修改（表情、语气词）。
  - 整段重写或没有改动时不记录。
- 存储（`history.ts`）：新表 `style_samples`（增量建表，老库兼容），最多 50 条。
- IPC：`styleSampleList` / `styleSampleDelete` / `styleSampleClear`。
- 设置页“润色个性化”：
  - 两个开关打开时弹确认框，写明发送到的 LLM 地址。
  - 风格说明改完自动保存。
  - 修改记录列表可逐条删除、清空。
- `mt-focus --caret-context`：macOS 密码框（`AXSecureTextField`）退出码 5（Windows 原本就不读密码框）。
- 评测集：新增 6 条个性化用例，旧提示词不支持，预期失败。

## 遗留

- 修改记录只认光标附近能对齐的改动：在写入内容前面加的称呼等会被忽略。
- Electron 应用第一次读取可能落空（与 D-012 相同）。
