# 界面与存储需求

> **状态：confirmed（2026-10-14，项目负责人）**

## 范围

包含：浮动条、主窗口（首页、历史、词典、会议、设置）、回答浮卡、菜单栏托盘，以及设置、API Key、历史与词典的本地存储。

## 规则

1. 首次使用时引导授予辅助功能与麦克风权限（来源：[README](../../README.md)）；使用内置引擎且模型未下载时，主窗口首页显示下载提示（大小、进度、速度、取消、失败可重试且从断点继续）（D-009）。
2. 应用常驻菜单栏托盘；关闭窗口不退出，从托盘打开主窗口或历史。
3. 浮动条为屏幕底部居中的小胶囊（D-010）：按住说话时只显示随音量跳动的波形；免手持时两侧显示取消与完成；改写/翻译/提问显示模式标签；处理中显示动画；写入成功闪 ✓ 后立即消失；出错时在胶囊上方显示原因。胶囊以外的透明区域点击穿透。
4. 历史只存本地，可复制、删除（来源：项目初始方案、D-002）。
5. API Key 存系统 Keychain，界面只显示掩码（D-002）。
6. 个人词典可手动添加、删除（来源：项目初始方案）。
7. 语音识别设置可选择内置本地引擎 / 云端 / 自建 whisper.cpp 服务；内置引擎可下载、切换、删除模型，设置识别语言与中文简繁。
8. 打包版未授权辅助功能时，权限面板说明“旧版本授权记录”问题，并提供「重置授权」（只清除本应用的记录后引导重新授权）。
9. 设置里可关闭「麦克风保持就绪」（默认开，D-011）。
10. 设置里可选择麦克风：默认「自动」（跳过虚拟设备、无声自动换），列出全部输入设备并标注虚拟设备。
11. 应用是普通前台应用：运行时 Dock 有图标、⌘Tab 可切换（浮动条不得改变应用类型）。
12. 设置里可打开「说话时在胶囊上方显示识别中的文字」（默认关闭，D-023）；词典页可关闭两个自动学习来源（即时生效）；自动学到的词标 ✦，删除后不再学回。
13. 设置里可选择最长录音时长（5/10/20/30/60 分钟，默认 20 分钟，D-014）。
14. 主窗口为左侧导航（D-017）：侧栏顶部「个人 ｜ 会议」切换；个人模式导航为首页、历史、词典，会议模式为会议；设置在侧栏底部，两种模式共用；会议进行中侧栏显示会议状态，点击回到该会议。
15. 首页显示问候、使用概览（累计字数、今天字数、节省时间、平均语速）、快捷键速查（按当前绑定）、权限与快捷键引擎状态、最近几条记录。
16. 历史按日期分组，可搜索。
17. 会议进行中，浮动条胶囊显示「会议中 hh:mm:ss」与暂停/结束按钮；整理中显示当前步骤（D-015）。
18. 应用显示当前版本：主窗口侧栏底部（版本 · 构建号）、设置 → 关于（版本、构建号、代码提交）、托盘菜单第一行、macOS「关于」面板。
19. 在线更新（D-028）：设置 → 关于 显示更新状态（尚未检查 / 正在检查 / 已是最新 / 有新版本与更新内容 / 下载进度 / 已下载 / 失败原因）和对应按钮（检查更新、下载更新、取消、重启并更新、自动安装失败时的「下载安装包」），以及「自动检查更新」开关；有新版本或已下载时侧栏版本号下方、托盘菜单第二行出现入口，点击打开「关于」。
20. 设置 → 润色 LLM 有「测试连接」按钮：用当前填写的地址、模型和 Key（Key 栏留空时用已保存的），不必先保存；收到模型的第一段输出即显示“连通正常”与耗时，失败时说明原因（Key、地址、模型名、网络、超时、不是 OpenAI 兼容接口）并附上服务端原话（来源：项目负责人，2026-10-18）。
21. 设置 → 润色个性化（D-040、D-041）：「参考光标前的文字」「学习我的修改习惯」两个开关默认关闭，打开时弹确认框说明读取或保存什么、发给哪个服务；个人风格说明改完自动保存；修改记录列表显示“写入 → 改后”，可逐条删除、清空。

## 必测不变量

- 浮动条不抢占用户应用的焦点。
- 用户文本在界面中按纯文本显示，不作为 HTML 解析。
- 设置与数据库只做向前兼容的增量变更（人工门禁）。
