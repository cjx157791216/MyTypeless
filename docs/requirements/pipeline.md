# 听写管线需求

> **状态：confirmed（2026-10-14，项目负责人）**

## 范围

包含：四种模式（听写、翻译、改写选中、语音提问）从开始录音到结果投递的全过程——音频采集、语音识别、本地清理、LLM 处理、写入请求、历史记录。

不包含：快捷键检测与写入实现（见[原生层](native.md)），窗口与设置界面（见[界面与存储](ui.md)）。

## 规则

1. 听写：口述内容经识别、润色后写入当前光标处；支持中英混说（来源：[README](../../README.md)）。
2. 翻译：用母语说，输出设置中指定的目标语言并写入光标处（来源：[README](../../README.md)）。
3. 改写选中：先选中文字，按主键后口述指令（更简短、更正式、换成英文……），改写结果替换选区；选区通过辅助功能接口在开口同时读取，不碰剪贴板（D-010）（来源：[README](../../README.md)、项目初始方案）。
4. 语音提问：回答显示在浮卡中，可复制或插入光标，不自动写入（来源：[README](../../README.md)）。
5. 润色目标：去口头填充词与无意义重复，改口只保留最终意图，口述列表整理成结构，按前台应用类别（代码、即时通讯、邮件、文档）适配文风（来源：项目初始方案）；时间、数量、金额、百分比用阿拉伯数字（成语、约数除外），中文与英文、数字之间加空格，口述“换行”“另起一段”执行为换行，不做简繁转换（D-038）。
6. 个人词典中的专有名词按词典写法输出（来源：项目初始方案）。
7. 未配置 LLM Key 时听写仍可使用，只做本地清理；翻译、改写、提问需要 LLM Key。
8. 录音过程中可按 Esc 取消（来源：[README](../../README.md)）。
9. ASR 支持云端 OpenAI 兼容与本地 whisper.cpp 两种模式（D-004）；音频处理完即弃，历史只存本地（D-002、D-005）。
10. 默认使用内置本地引擎（D-009）：安装包不含模型，首次使用时提示下载（识别语言为中文、英文或自动时推荐「中文高精度」FireRedASR2，约 1.3GB，自动加标点；其他语言推荐「多语种」Whisper，D-027）；模型未下载时按下快捷键不开始录音，直接提示并打开主窗口的下载入口。
11. 内置引擎的识别语言默认跟随系统（中文系统按中文识别，中英混说仍可识别），中文输出默认跟随系统地区（简体 / 繁体）。
12. 实时转写（D-013、D-023）：说话时在停顿处后台识别，松手时若最后一句已识别则立即写入；说话时胶囊默认只显示波形、不显示文字，可在设置里打开「说话时在胶囊上方显示识别中的文字」。
13. 自动词典（D-012）：从写入后的修改与常用英文专有名词中学习，收录的词用于后续识别提示。
14. 最长录音时长默认 20 分钟（D-014）：最后 1 分钟胶囊上倒计时，到时自动结束并照常写入。
15. 光标上下文（D-040）：开启后听写润色参考光标前最多 300 字，随请求发给所配置的 LLM，不保存；密码框不读；默认关闭。
16. 风格学习（D-041）：开启后保存写入后被用户改过的听写结果（本机最多 50 条，可删除），润色时挑最多 5 条作示例；个人风格说明随润色请求发送；默认关闭。

## 必测不变量

- 口述内容只被整理，不被当作指令执行：口述“帮我写一封请假邮件”应输出这句话本身。
- 听写润色提示词的固定部分（规则与示例）不随场景、词表变化；示例不与评测集用例重复（D-038）。
- 松开快捷键时最后一个词不丢失。
- 内置引擎识别期间不联网；只有下载模型时联网。
- 实时转写同一时刻最多一个识别请求；已定稿的部分不再重复识别；最终写入的文字覆盖全部语音。
- 长录音：实时转写内存中只保留未定稿的音频；整段识别每段不超过 5 分钟（云端上传大小限制）；到达上限自动结束时说过的话照常写入。
- 追踪修改只读取插入那一段；读到的文字除风格学习开启时保存的“写入 → 改后”外不保存、不上传；前台应用切换后不再读取（D-012、D-041）。
- 光标上下文只在开启后的听写中读取，只进入本次润色请求，不进历史；包在 `<context>` 中并声明不是指令（D-040）。
- 麦克风保持就绪期间，按下快捷键同时开口，开头的字不丢（预录约 0.3 秒，只在内存中）。
- 采集不做通话降噪与回声消除，16kHz 由浏览器重采样；识别结果中文语境下使用中文标点。
- 系统默认输入是虚拟设备（只出静音）时，自动改用真实麦克风；所选麦克风只出纯静音时自动换一个并提示。
- 润色失败时仍写入本地清理结果；写入失败时结果在剪贴板中（D-008）。
- 识别结果没有实际内容（空、幻觉、只有语气词或标点）时不调用 LLM、不写入，提示没有识别到内容（D-034）。
