# 会议模式需求

> **状态：confirmed（2026-10-15，项目负责人；2026-10-17 增加线上会议，D-033）**

本领域为原创设计（D-001：提示词、文案、界面全部原创）。

## 范围

包含：个人/会议模式切换；用麦克风录制线下会议、截取会议软件的声音录制线上会议，并实时转写；区分不同说话人并命名、纠正；声纹记忆；每人发言总结；会议纪要的生成、编辑、导出；会议存档。

不包含：录音回放；多设备同步；实时翻译；会议日历集成。

## 已确认的取舍（2026-10-15，项目负责人）

- 音频来源：只用麦克风 / 麦克风 + 会议软件的声音 / 只用会议软件的声音，开会时三选一（D-033，2026-10-17 起；原为只用麦克风）。
- 会议期间录音临时保存在本机，纪要生成后自动删除，只保留文字。
- 给说话人命名后可保存声纹，下次会议自动认出；声纹只存本机，可查看、删除。
- 界面改版与会议模式一起设计、一起交付。

## 规则

### 模式与入口

1. 主窗口侧栏顶部有「个人 ｜ 会议」切换（D-015、D-017）。个人模式与现在完全一致；会议模式进入会议工作区（会议列表 + 当前会议）。切换模式本身不开始录音。
2. 托盘菜单提供「开始会议 / 结束会议」。

### 会议进行中

3. 点「开始会议」后开始录音：会议主题可选填；必须选参会人数（1～10 人，默认 2 人，记住上次的选择；托盘开会用上次的人数）——会议中和会后都能在说话人栏随时修改，改后立即按新人数重新区分（D-020、D-021）；每次开始时提示“请告知参会者正在录音转写”。
4. 离麦克风稍远的人说话也要能分出句子并转写：会议录音边录边降噪后分句，识别前把小声放大到正常音量（D-024）；离得太远、房间太吵时准确率仍会下降，建议把麦克风放在桌子中间或使用外接会议麦克风。会议页实时滚动显示转写：每段带说话人、开始时间和文字；一句话说完约 1～3 秒出现。
5. 每段文字定稿后立即存入本地数据库；应用异常退出时最多丢失最后几十秒，下次启动提示继续整理该会议。
6. 可暂停 / 继续 / 结束；底部胶囊显示「会议中 hh:mm:ss」。
7. 会议进行中 Fn 听写暂停：按 Fn 时胶囊提示“会议进行中”；会议结束后自动恢复。
8. 单场会议最长 4 小时；最后 5 分钟提醒，到时自动结束并照常整理；使用电池时提醒接电源。

### 说话人

9. 说话人按参会人数和声音自动区分（D-019、D-021、D-025；两人间隔很短、一人说完另一人立刻接话时也要分开，会议说了一阵后按已知各人的声音找换人位置）：标注「说话人 1 / 2 / …」，最多分出所选人数，且一定分出所选人数（说得少的一方不会被并掉）；不停顿就接话的两个人也要分开；已保存声纹的人直接标名字。不按声音自动判断人数；较早没有设置人数的会议保持原有分组。
10. 会议中和会议后随时可以：点说话人栏或发言前的名字改名（所有发言同步更新）；把某一段改归另一个人；合并两个说话人。
11. 改名时「记住这个声音」默认勾选，可取消（D-018），保存声纹；之后的会议里，这个人说过两句以上后（会议中约 20 秒内）自动标出名字，一个声纹在一场会议里只标给一个人（D-022）；设置里可查看、改名、删除已保存的声纹（D-016）；声纹模型可在设置里提前下载或删除，未下载时首次开会自动下载。
12. 每场会议为每个说话人保留一个声音特征向量，并保存每一句的声音特征向量（不是录音，无法还原成声音），用于会后“记住这个声音”与按人数重新区分；删除会议时一并删除（D-016、D-020）。

### 会议结束后

13. 结束会议时选择「生成纪要」或「只保存记录」（D-019）。结束后自动整理：用整场数据重新判定说话人 →（选择生成时）生成每人发言总结与会议纪要；只保存的会议之后可随时生成纪要。
14. 会议纪要包含：主题、时间、时长、参会人；议题与讨论要点；决议；待办（事项、负责人、截止时间）；未决问题；各人发言摘要。
15. 纪要可编辑、复制、导出为 Markdown 文件；改名或改归属后可重新生成纪要。生成纪要时在本地把说话人名字加粗（`**名字**`，参会人一行也是），复制、导出的 Markdown 带着加粗；界面上加粗的说话人名字按该说话人的颜色显示。单字名字只在像人名的位置（句首、标点或介词后，接“表示、认为、提出”等）加粗，避免把“完成”“成本”之类的词标出来；之前生成的纪要重新生成后才有标记。
16. 总结和纪要使用已配置的 LLM（BYOK）；未配置 Key 时只保存转写稿，并提示配置后可生成。长会议先分段整理提要（按长度均分，每次发给模型的内容不超过约 1.2 万字，最多 3 段同时进行），提要太多时逐层合并，再汇总成纪要；生成失败后重新生成只补没完成的部分；推理模型（如强制深度思考的模型）只要还在输出就继续等待。
17. 整理完成后删除该会议的临时录音（D-016）。

### 会议存档

18. 会议列表显示标题、日期、时长、参会人，可搜索；删除会议即删除其文字、说话人数据和尚未删除的临时录音。

### 线上会议（D-033）

19. 开始会议时选择声音来源：只用麦克风（默认）/ 麦克风 + 会议软件（现场也有人）/ 只用会议软件的声音；选了会议软件时再选截取哪个应用：只列正在运行的通话软件（腾讯会议、微信、飞书等）和浏览器（标“网页会议”），然后是“全部系统声音”，其余正在运行的应用收在“其他应用…”里，选它才展开；没用过线上会议时默认选第一个通话软件；回到主窗口时自动刷新列表（D-039）。都记住上次的选择，托盘开会用上次的选择。系统低于 macOS 14.2（Windows 低于 Windows 11 / Windows 10 build 20348）时只能用麦克风。
20. 麦克风 + 会议软件：现场（麦克风）与线上（会议软件）分别选人数、分别区分说话人，默认名「现场 N」「线上 N」；说话人栏分两组，各有人数可随时改；改归属、合并只在同一组内。只用会议软件的声音时只选一个人数，默认名「说话人 N」。
21. 外放时对方的声音会被麦克风再录一遍：麦克风这一路自动去掉这部分，同一句话只出现在线上；现场与线上同时说话时现场的话保留。开会时提示建议戴耳机，检测到回声时提示一次。
22. 首次使用时系统请求「录制系统音频」权限，必须在开会前完成（允许后系统会重新打开 MyTypeless）：授权框还没回应时不开始会议并提示先允许；一直收不到所选应用的声音时提示去 系统设置 → 隐私与安全性 → 录屏与系统录音 允许。
23. 会议软件的声音与麦克风录音同等对待：只在会议期间临时保存在本机，整理完删除，任何时候不上传。

## 必测不变量

- 会议录音（麦克风与会议软件的声音）只在本机临时保存，纪要生成后（或会议被删除时）删除；任何时候不上传音频。只截取用户所选应用（或全部系统声音，排除 MyTypeless 自己）的声音（D-033）。
- 声纹只存本机，只为用户命名并勾选“记住”的人保存；删除后立即生效。
- 会议进行中不影响其他工作：识别引擎低优先级、同一时刻最多一个识别请求；说话人区分在 CPU 上低优先级运行。
- 已定稿的文字不因后续步骤失败而丢失（D-008 的会议版）：LLM 失败时转写稿完整保留。
- 发给 LLM 的只有转写文字和说话人名字。
