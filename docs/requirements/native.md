# 原生层需求

> **状态：confirmed（2026-10-14，项目负责人）**

## 范围

包含：全局快捷键（按住说话 / 免手持 / Fn 组合）、文字写入、选中文本抓取、前台应用识别、辅助功能权限检测。

不包含：会话编排（见[听写管线](pipeline.md)）。

## 规则

1. 默认快捷键（D-010）：主键 `Fn` 听写，`Fn+空格` 语音提问，`Fn+Shift` 翻译；改写不需要单独的键（选中文字后按主键）；均可在设置中修改，也支持 `ropt` 等单修饰键或 `opt+space` 等组合。
2. 主键：按住说话、松开写入；轻按（0.3 秒内松开）进入免手持，再按一下结束；免手持或提问/翻译录音中再按主键即结束（D-010）。
3. 按住主键时又按了组合中的键（空格、Shift）：撤销本次听写，改为触发对应组合；按了其他键（如 Fn+方向键）则视为系统组合键，放弃本次触发、按键照常生效（D-010）。
4. 写入采用降级链：键入 → 辅助功能 API 设值 → 剪贴板粘贴（来源：项目初始方案；第二级未实现，见 GAP-005）。
5. 键盘监听只匹配已注册的快捷键，不记录其他按键（D-002）。
6. 全局快捷键与写入需要辅助功能权限，设置页可检查与引导授权（来源：[README](../../README.md)）；开发模式下权限归属于启动它的终端应用，设置页要指明该应用。
7. 主键含 Fn 时，若系统「按下 🌐 键时」不是「无操作」，主窗口提示并提供打开键盘设置的按钮（D-010）；用 Fn 开始录音时胶囊上也提示一次，这次听写写完后自动打开键盘设置（每次启动最多一次，录音中不打开，避免抢走焦点）（D-043）。
8. 自动写入方式：不超过 160 字且无换行时逐字键入，否则粘贴（D-007）。
9. 🌐 键无论被系统报为 63 号键（Fn 修饰键）、179 号键，还是两者都报，都能按住说话；同一次按键只触发一次（D-043）。

## 必测不变量

- 触发快捷键本身不能落入目标应用（例如 `Fn+空格` 不得输入空格、`opt+space` 不得输入不换行空格）。
- 写入或抓取选区临时占用剪贴板后，要恢复用户原有的剪贴板内容。
- 未授权辅助功能时，应用仍可启动，主键改用 `⌥+空格` 按一下开始/结束；授权后无需重启即恢复。
