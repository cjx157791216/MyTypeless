## 总体阶段

M0～M4 里程碑（需求整理、听写闭环、原生层与本地存储、四模式、打包）均已交付，可在本机自用。语音识别默认改为内置本地引擎（D-009）：安装后下载一次模型即可离线使用（GAP-011，待真机验证）。交互改为按住 Fn 说话（D-010）：按住 Fn 说话、轻按免手持、选中即改写、底部小胶囊（GAP-012，待真机验证）。新增原创的会议模式（D-015、D-016）与主窗口改版（D-017）：录制线下会议、本地区分说话人并记住声纹、会后生成纪要，自动检查与打包版端到端（合成语音）通过，待真人真机验证（GAP-016～019）。随后做了一轮稳定性修复（GAP-001），自动检查全部通过，但快捷键与写入还没有在授权环境下真机验证。对外分发前还差 Developer ID 签名与公证（GAP-009）。项目以个人名义 MIT 开源到 GitHub（D-030，GAP-021），安装包发布在本仓库的 Releases，经在线更新分发（D-028、D-032）。Windows 版（x64）自 v0.3.1 起随版本发布（D-035、D-036），由社区贡献移植（GAP-008）。
