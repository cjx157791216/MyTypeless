设置

通用

快捷键

格式如 fn、fn+space、ropt（右 Option）、opt+space；提问/翻译按一下开始，再按一下或按主键结束。外接键盘的 Fn 系统读不到时，可改用 ropt
格式如 rctrl（右 Ctrl）、rctrl+space、键盘没有右 Ctrl 时可用 rshift（右 Shift，翻译 rshift+ctrl）或 ralt（右 Alt）；提问/翻译按一下开始，再按一下或按主键结束。单独的修饰键按住约 0.15 秒才开始，所以用它打大写字母等组合不会误触发。选中文字后按主键会自动改写，但有的程序读不到选区（如 VS Code 的编辑器、Notepad++），会按普通听写覆盖选中内容：在这些程序里请给「改写选中」单独设一个键（它通过复制读取选区）。Windows 键盘的 Fn 系统读不到，不能用作快捷键

语音识别

指定语言比自动检测快约一倍；选“中文”时英文和中英混说同样能识别。模型保存在本机，音频不离开电脑。
连接你自己运行的 whisper.cpp 服务（一般用内置引擎即可）：
whisper-server -m <模型.ggml> --host 127.0.0.1 --port 8178
